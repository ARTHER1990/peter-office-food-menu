# 🍱 Peter Office Food Menu Alert (แผงแจ้งเตือนเมนูอาหารประจำวัน)

แอปแจ้งเตือนรายการอาหารกลางวันประจำบริษัท สำหรับ macOS ทำงานบน Menu Bar และแจ้งเตือนอัตโนมัติเวลา 10:50 น. ของทุกวัน

## ✨ คุณสมบัติ
- **Menu Bar Icon:** ไอคอนช้อนส้อมมินิมอลบนแถบข้างนาฬิกา แสดงเมนูวันนี้, พรุ่งนี้ (Preview) และเมนูทั้งเดือน
- **Daily 10:50 AM Auto-Popup:** แจ้งเตือนขึ้นกลางหน้าจอบนสุด 5 วินาทีแล้วหายไปเองอัตโนมัติ
- **Cloud Auto-Sync:** ดึงข้อมูลเมนูล่าสุดจาก GitHub อัตโนมัติ เพื่อนๆ ในทีมไม่ต้องกดอัปเดตเอง

## 🚀 วิธีติดตั้งลงเครื่อง Mac เพื่อนๆ (คลิกเดียว)
เปิด Terminal แล้วรันคำสั่ง:
```bash
curl -sL https://raw.githubusercontent.com/ARTHER1990/peter-office-food-menu/main/install.sh | bash
```

## 🛑 วิธีถอนการติดตั้ง
```bash
curl -sL https://raw.githubusercontent.com/ARTHER1990/peter-office-food-menu/main/uninstall.sh | bash
```
