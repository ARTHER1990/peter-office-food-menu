# 🍱 Crazy Factory Office Food Menu Alert (Peter Food Menu)

ระบบแจ้งเตือนและแสดงรายการอาหารกลางวันสำหรับพนักงานออฟฟิศ **Crazy Factory** ทำงานเป็น Background Menubar App บน macOS พร้อมระบบแจ้งเตือนแบบ Floating HUD, คำนวณแคลอรี่และสารอาหาร, ระบบติดดาวเมนูโปรด, และการอัปเดตข้อมูลอัตโนมัติผ่าน Cloud

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 🍽️ แสดงรายการอาหารวันนี้ พรุ่งนี้ และทั้งเดือน
* **แท็บ "วันนี้" & "พรุ่งนี้":** แสดงชื่อเมนูหลัก แกง/ต้ม ของหวาน และข้อมูลโภชนาการแบบละเอียด
* **แท็บ "ทั้งเดือน":** แสดงตารางอาหารครบทุกวัน แยกหมวดหมู่ตามเดือนชัดเจน พร้อมป้ายแคลอรี่ `🔥 ~xxx kcal`

### 2. 🥗 ข้อมูลโภชนาการ & การเผาผลาญ (Nutrition & Burn Engine)
* **เกณฑ์การคำนวณ:** คำนวณต่อ 1 เซ็ต/1 เสิร์ฟ โดยยึดหลัก **ข้าวสวย 1 ทัพพี (~80 kcal)** เป็นมาตรฐาน
* **ของหวานหมุนเวียน (Rotating Desserts):** คิดค่าเฉลี่ยกลางมาตรฐานที่ **~130 kcal** *(ผลไม้สด ~60-80 kcal / ขนมไทย-เบเกอรี่ ~150-180 kcal)*
* **สารอาหารหลัก (Macros):**
  * 🥩 **โปรตีน (Protein):** เสริมสร้างกล้ามเนื้อและซ่อมแซมร่างกาย
  * 🍚 **คาร์โบไฮเดรต (Carbohydrates):** พลังงานหลักของวัน
  * 🥑 **ไขมัน (Fat):** ไขมันจำเป็นและไขมันจากอาหาร
* **🏃‍♂️ วิธีเบิร์นล้างแคลอรี่:** คำนวณเวลาการออกกำลังกายที่ต้องใช้ เช่น `วิ่ง ~40 นาที` หรือ `เดินเร็ว ~70 นาที`
* **💡 ไฮไลท์สุขภาพ:** คำแนะนำและข้อดีของแต่ละมื้ออาหาร

### 3. ⭐ ระบบติดดาวเมนูโปรด (Favorites System)
* ผู้ใช้สามารถกด ⭐ ติดดาวเมนูที่ชอบในแต่ละวันได้
* ข้อมูลการติดดาวจะถูกบันทึกในเครื่องของผู้ใช้แต่ละคนอย่างอิสระ
* เมื่อถึงวันที่มีเมนูโปรด หน้าต่างป็อปอัปแจ้งเตือนจะแสดงป้ายเด่นชัดว่า **`⭐ เมนูโปรดของคุณ!`**

### 4. ⚙️ การตั้งค่าเวลาและเสียงแจ้งเตือน (Custom Settings)
* **⏰ ปรับเวลาแจ้งเตือนได้ตามใจชอบ:** `10:30`, `10:45`, `10:50`, `11:00`, `11:30` น.
* **🔔 สวิตช์เปิด/ปิดเสียงเตือน:** พร้อมปุ่มทดลองฟังเสียง Chime หรูหรา
* **🖥️ สวิตช์เปิด/ปิดป็อปอัป:** สำหรับคนที่ต้องการดูเฉพาะบนแถบ Menu Bar

### 5. ☁️ ระบบซิงค์ข้อมูลและอัปเดตอัตโนมัติ (Silent Cloud Sync)
* ตรวจเช็คและดึงข้อมูลเมนูใหม่จาก GitHub ทุกๆ **30 นาที**
* ตรวจหาตัวโปรแกรมเวอร์ชันใหม่ทุกๆ **2 ชั่วโมง** และอัปเกรดตัวเองแบบ Background ไร้เสียงรบกวน
* รองรับ Mac ทุกสถาปัตยกรรม (**Universal Binary: Intel x86_64 + Apple Silicon ARM64**)
* ป้องกันการเปิดโปรแกรมซ้ำด้วยระบบ **Single-Instance Lock**

## 📸 วิธีอัปเดตเมนูประจำเดือนใหม่ (Monthly Update Workflow)

1. นำไฟล์รูปถ่ายใบเมนูของเดือนใหม่ วางลงในโฟลเดอร์ [`Menu_Photos/`](file:///Users/art/Desktop/ART_JOB/05_Research_and_Development/PETER_FOOD_MENU_ALERT/Menu_Photos)
2. สั่งปีเตอร์ว่า *"อัปเดตเมนูเดือนใหม่ให้หน่อย"*
3. ปีเตอร์จะดำเนินการตาม **Protocol ใน [`SKILL.md`](file:///Users/art/Desktop/ART_JOB/05_Research_and_Development/PETER_FOOD_MENU_ALERT/SKILL.md)**:
   * สแกนข้อความจากรูปภาพ
   * คำนวณแคลอรี่ สารอาหาร และเวลาออกกำลังกายตามเกณฑ์ข้าว 1 ทัพพี
   * นำรายการไปต่อท้ายวันที่ยังเหลือของเดือนเดิม
   * ซิงค์ขึ้น GitHub Cloud ทันที
