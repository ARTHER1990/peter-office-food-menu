# 📚 โปรเจกต์: ข้อสอบครูผู้ช่วย วิชาเอกภาษาอังกฤษ (3 ระดับ)

โปรเจกต์จำลองข้อสอบแข่งขันเพื่อบรรจุและแต่งตั้งบุคคลเข้ารับราชการเป็นข้าราชการครูและบุคลากรทางการศึกษา ตำแหน่งครูผู้ช่วย (วิชาเอกภาษาอังกฤษ - ภาค ข) สำหรับส่งให้น้องชายของคุณอาร์ตฝึกทำทางไกลพร้อมระบบส่งรหัสคำตอบกลับมาตรวจอัตโนมัติ

2. **Part 2: Vocabulary & Word Usage (ข้อ 11–20):** 10 คะแนน

5. **Part 5: English Language Teaching Methodology / Pedagogy (ข้อ 44–50):** 7 คะแนน
